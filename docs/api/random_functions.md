# Random functions

A random function is a distribution over functions, and a random measure is a distribution over distributions.
The operations `random_log_prob` and `random_unnormalized_log_prob`, which return a random measure's log-density as a random function, are on [Operations](operations.md), and the bootstrap random measure `BootstrapDistribution` is with the resampling families on [Distributions and families](distributions.md).
